# DIXWAY — Immersive Sound Project

Static landing page for DIXWAY.

## Publish on GitHub Pages

1. Create a new GitHub repository and upload the contents of this folder.
2. In the repository, go to **Settings → Pages**.
3. Choose **Deploy from a branch**, then select the `main` branch and `/ (root)` folder.
4. Save. GitHub will publish the site at the URL shown on that page.

No build process or dependencies are required. The entry page is `index.html`.
